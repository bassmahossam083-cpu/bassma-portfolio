بناء وتطوير المحلل اللغوي للمترجمات (LALR Compiler Parser)LALR Parser Construction & Bottom-Up Parsing Simulator

Compiler Construction | LALR Parsing | LR(1) & LR(0) Automata | Shift-Reduce Simulation | Conflict Detection

مشروع متقدم لبناء المحلل اللغوي LALR Parser للمترجمات من الصفر دون مكتبات خارجية. يتضمن توليد حالات LR(1) ودمجها لبناء جداول ACTION/GOTO، واكتشاف تعارضات Shift/Reduce، ومحاكاة عملية الإعراب بأسلوب (Stack-Input-Action).

Designed a bottom-up LALR Parser from scratch for compiler design. Generated LR(1) item sets, merged identical LR(0) cores to build compact ACTION/GOTO tables, detected grammar conflicts, and simulated shift-reduce parsing using the three-column approach.

مشروع تطبيقي لبناء خادم وتطبيق عميل موزع عبر شبكة LAN ببروتوكول TCP. يتضمن خادماً متعدد المسارات (Multithreaded Server) لحساب الدوال الرياضيات، وقياس زمن الانتقال والدوران (RTT) لتحليل كفاءة الشبكة ومعالجة مشاكل الترميز والجدر النارية.

Designed a distributed multithreaded TCP Client-Server network system using Java Sockets over a LAN. Processed mathematical requests concurrently, measured real-time Round-Trip Time (RTT) latency, and optimized cross-platform network socket I/O.

تطوير واختبار أنظمة تشفير المفتاح السري (Secret-Key Encryption & Crypto Lab)Secret-Key Encryption & Dictionary Attack Implementation

OpenSSL | Java Crypto Library | Linux / Ubuntu VM | SEED Labs | AES Cryptography

مشروع تطبيقي في أمن المعلومات على بيئة SEED Labs لتشفير البيانات بـ OpenSSL واستخدام خوارزميات AES بأنماطها (CBC, CFB, CTR)، وتحليل أمان نمط ECB مقابل CBC على الصور، بالإضافة لكتابة برنامج Java لتنفيذ هجوم القاموس (Dictionary Attack) وكسر مفتاح التشفير.

Cybersecurity project evaluating secret-key encryption using OpenSSL on SEED Ubuntu VM. Tested AES modes (CBC, CFB, CTR), analyzed ECB vs. CBC image pattern leaks, and implemented a Java-based dictionary attack to recover AES encryption keys.

Python | Scikit-Learn | Decision Trees | Data Preprocessing & Balancing

بناء نموذج تعلم آلة لفرز البريد العشوائي (Spam) عبر مجموعة بيانات Spambase. تضمن العمل معالجة Overfitting بضبط عمق الشجرة (Max_Depth=7)، ومعالجة عدم توازن البيانات (Undersampling) لرفع دقة النموذج إلى 91.64%، وتحويل الشجرة لقواعد منطقية Visualized Rules.

حل مشكلة الملكات N-Queens باستكشاف خوارزميات CSPSolving N-Queens Puzzle as a Constraint Satisfaction Problem (CSP)

Python | Artificial Intelligence | CSP | Backtracking | Forward Checking | MAC

تمثيل وحل مشكلة N-Queens الكلاسيكية كـ CSP ومقارنة أداء خوارزميات (BT, FC, MAC) على رقع بأحجام مختلفة ($N=4, 8, 16, 32, 64$). أظهرت النتائج تفوق MAC في التقليم (Pruning) بينما حققت FC أفضل كفاءة زمنية للأحجام الكبيرة.

Formulated and solved the N-Queens puzzle as a CSP, evaluating BT, FC, and MAC algorithms across board sizes up to N=64. MAC achieved optimal domain pruning, while FC scaled most efficiently for large search spaces.
